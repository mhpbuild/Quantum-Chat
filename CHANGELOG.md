## 0.1.1 — 2026-11-16

Initial publication in this new public repository, using the existing 0.1.1
software snapshot. Earlier development history is retained in a private archive.

- Two-way terminal chat and loopback-only superdense-coding simulator.
- Observer viewer, three executable scientific notebooks, and bilingual documentation.
- MIT license, installation instructions, package metadata, and CI.

Scientific experiment dates and random seeds are preserved for reproducibility.
This project is a local educational simulation, not a physical quantum network.
